Questions

Is it really free?

Yes. Typfix is open source (MIT) and corrects your text with a free model running on your own Mac through Ollama. There's no account, no subscription, and no server bill - because there's no server. The optional Claude Code backup is also free with a Claude sign-in.

Does my text get sent anywhere?

With the default local model, no - it's processed entirely on your Mac. If you fall back to the Claude Code backup, the selected text goes to Anthropic under your own Claude account's terms, exactly as it would if you used Claude Code directly. There is no other network activity, no analytics, and nothing stored.

Which apps does it work in?

Effectively all of them: Safari, Chrome, Arc, Slack, Discord, Mail, Notes, Messages, Notion, Word, Google Docs, and any standard text field. In Cursor and VS Code, the companion extension gives an even smoother inline experience. Terminals get the correction on your clipboard instead of pasted.

Will it make my casual messages sound stiff?

No - that's a core design goal. It preserves tone, slang, humor and emojis. It corrects mistakes without rewriting your personality, and you can pick Basic, Natural, or Professional modes.

What permission does it need?

One: macOS Accessibility, so it can read the text you select and replace it with the corrected version. That's the only permission, and it's the only thing it does with it. It is not sandboxed by necessity, runs the hardened runtime, and requests nothing else.

Is there a prebuilt download?

Not yet - for now you build it locally in about a minute (it works with just Apple's free Command Line Tools; no Xcode needed). A signed, notarized download is on the roadmap.
